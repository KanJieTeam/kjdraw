# Node + TypeScript

```sh
npm install
npm run start
```

The starter creates a 5 mm-radius circle, writes `output/circle.kjd` and `output/circle.dxf`, reopens both files, and prints a JSON verification receipt. Set `KJDRAW_STARTER_OUTPUT` to select a different output directory.

If TypeScript cannot resolve the package, confirm Node.js 22+ and reinstall dependencies. If DXF reopening fails, keep the emitted file and error output together when reporting the issue.

Continue with the [Editor API](https://kanjieteam.github.io/kjdraw/docs/latest/api/) or the [complete TypeScript reference](https://kanjieteam.github.io/kjdraw/docs/latest/api/reference/).
