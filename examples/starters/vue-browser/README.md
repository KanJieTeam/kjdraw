# Vue browser

```sh
npm install
npm run dev
```

This Vite app mounts `KJDraw` from the supported Vue entry and controls it through its exposed typed ref. Use `npm run build` for a production bundle. See the [Vue guide](https://kanjieteam.github.io/kjdraw/docs/latest/vue/) and [Editor API](https://kanjieteam.github.io/kjdraw/docs/latest/api/).
