# Vanilla browser

```sh
npm install
npm run dev
```

The Vite app mounts the complete editor and creates a 5 mm-radius circle. Use `npm run build` for a production bundle. The host element must have a non-zero height. See the [Quickstart](https://kanjieteam.github.io/kjdraw/docs/latest/quickstart/) and [Editor API](https://kanjieteam.github.io/kjdraw/docs/latest/api/).
