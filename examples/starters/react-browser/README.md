# React browser

```sh
npm install
npm run dev
```

This Vite app mounts `KJDraw` from the supported React entry and controls it through a typed ref. Use `npm run build` for a production bundle. See the [React guide](https://kanjieteam.github.io/kjdraw/docs/latest/react/) and [Editor API](https://kanjieteam.github.io/kjdraw/docs/latest/api/).
