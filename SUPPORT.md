# Support

KJDraw support is public, reproducible and version-aware. Search existing issues first, then open a GitHub issue with a minimal synthetic example, the exact KJDraw version, environment, file format/version and expected result. Do not upload confidential drawings.

## Supported releases

| Release line | Status | Maintenance |
| --- | --- | --- |
| Latest stable `1.x` | Stable contract after 1.0 promotion | Security and correctness fixes |
| Latest `1.x` release candidate | Evaluation | Release-blocking fixes |
| `0.x` previews | Preview | Best effort until 1.0 |

Only the latest patch of a supported line receives routine fixes. Deprecations remain documented for at least one minor release before removal. A major release may change the public contract only with migration notes. End-of-life is announced in release notes and this file before support ends.

## Response targets

The community issue tracker is best effort; it is not a commercial SLA. Maintainers target initial triage within seven calendar days. Security reports follow the private acknowledgement and remediation targets in [SECURITY.md](SECURITY.md). Enterprise integration, deployment and response guarantees are separate from the Apache-licensed project.

Questions about private Kanjie products, customer data, industry templates or professional services are out of scope for this repository. Contact [kanjieteam@163.com](mailto:kanjieteam@163.com) for those topics.
