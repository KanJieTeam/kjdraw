KJDRAW / DOCUMENTATION

CAD infrastructure you can build on.

A framework-independent drawing model, deterministic command system, DXF/KJD/KJP file pipeline and Rust/WebAssembly geometry backend for engineering applications and AI agents.

Quickstart

Install the dependency-free SDK, create a document, and commit geometry through the same command path used by the live workbench.

npm install @kanjieteam/kjdraw
import { createKJDrawSDK } from '@kanjieteam/kjdraw'

const sdk = createKJDrawSDK()
const drawing = sdk.createDocument({
  documentId: 'hello-cad',
  units: 'millimeter',
})

await sdk.executeCommand('CREATE', {
  type: 'LINE',
  payload: { start: [0, 0, 0], end: [100, 0, 0] },
})

console.log(drawing.revision) // 1

Installation

KJDraw ships as ESM with TypeScript declarations and no runtime npm dependencies. Node.js 22+ is recommended for tooling; modern evergreen browsers are supported.

TypeScript / ESM

The public model is framework-independent. Subscribe to document events and project state instead of coupling the core to a component lifecycle.

const off = sdk.events.on('command:committed', ({ receipt }) => {
  console.log(receipt.afterRevision)
})

await sdk.executeCommand('MOVE', { ids: ['entity-1'], dx: 25, dy: 0 })
off()

const drawing = await sdk.readDocument(await file.arrayBuffer(), { format: 'DXF' })
const dxf = await sdk.writeDocument(drawing, { format: 'DXF', version: '2018' })

Commands and transactions

The live workbench is a reference application built only with public APIs. Fork its shell, replace the renderer, or use the core headlessly inside an existing engineering product.

Architecture boundaryThe SDK owns drawing truth. UI stores and renderers are projections. File and compute providers are explicit adapters.

Agent-native CAD

An agent proposes a bounded command envelope. KJDraw binds it to the exact document revision, lets a human inspect the result, and only commits after explicit confirmation.

const envelope = sdk.createCommandEnvelope('MOVE', {
  ids: surveyPointIds, dx: 3, dy: 0,
}, { origin: 'ai', mode: 'plan', expectedRevision: drawing.revision })

const preview = await sdk.executeCommandEnvelope(envelope)
