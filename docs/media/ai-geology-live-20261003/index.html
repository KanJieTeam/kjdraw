What was checked

Every approved revision is compared with a separately compiled expected target: exact source facts, unchanged unrelated facts and objects, and native CAD geometry. The final workflow also exercises native undo, redo, actual browser DXF download and DXF reopening. The manifest includes every captured model request and reported token receipt, including rejected attempts and repairs.

This recorded run used 21 actual requests. The provider reported deepseek-flash for the requested deepseek-chat alias: 380,008 input + 4,492 output = 384,500 total tokens. One invalid boundary proposal was rejected and repaired before review; its 40,321 tokens are included. No unavailable-viewer state was observed by the recorder's browser mutation gate. The preceding run failed to produce a fifth-round proposal and is included in the development-run history.

Reproduce the run

Check out the repository, install its development dependencies and build. Use Node.js 22+, the repository's Playwright setup and your own DeepSeek credential in KJDRAW_DEEPSEEK_API_KEY. Never put a key in the command or commit it.

npm install
node scripts/build.mjs
node scripts/record-synthetic-geology-demo.mjs --live --output .cache/my-live-run --model deepseek-chat --timeout-ms 180000

Use a new output directory for every run. KJDRAW_CHROME_PATH can select an existing Chrome installation. This calls the real paid API; responses, timing and cost can differ. The recorder rejects preset model endpoints and retains failed-run evidence.

Scope and provenance

  • All eight holes, 48 intervals, observations and patterns are original public synthetic data, not a private project. No actual organization or personnel information is used.
  • The starting drawing is built by KJDraw's trusted host compiler. The ten subsequent edits use real model calls; initial AI creation is not claimed.
  • The reproducible harness performs the reviewer approvals. This is not independent human-user acceptance.
  • Edits use the retained source-backed document. The exported DXF preserves supported native graphics, not its source recipe or internal UUIDs. Arbitrary imported DXF source reconstruction is not claimed.
  • This is a demonstrated workflow, not a comparative benchmark or evidence of universal correctness or token savings.
