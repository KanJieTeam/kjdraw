# Provider usage and timing evidence — 2026-09-10

KJDraw now extracts explicit provider usage fields for its four non-streaming model protocols and retains those observations through the task runner. It does not estimate tokens from characters, drawing entities or request bytes.

`extractKJModelUsage` distinguishes reported counters from totals computed from complete components. OpenAI input/output counters already include cache/reasoning subsets. Anthropic input totals add the separately reported uncached, cache-read and cache-write components. Gemini output totals include candidate and thought components. Missing components remain unavailable; negative, noninteger, unsafe and inconsistent counters are diagnosed. Counts, their sources and invalid field paths are returned without response text or credentials.

The adapter times its actual host transport call and exposes an isolated `onUsage` observer. Already received usage survives response refusal, truncation and protocol-size rejection. Observer exceptions do not change CAD execution. The runner retains every attempted turn, normalized sums where available, transport wall time and separate overall run wall time. A missing, malformed or duplicate observation cannot turn into a zero-cost turn or a complete total. A late transport response after cancellation can reach the host observer but cannot rewrite a previously returned runner result.

Validation: eight initial extraction cases and nine adapter/runner usage cases passed, including all four protocol field layouts, cache/reasoning inclusion, unsafe totals, rejected and truncated responses, actual delayed transport timing, cancelled late responses, absent usage, callback exceptions and custom bridges. The related model/progress/capability suites passed as part of 71 focused cases. Three further compatibility cases bring the focused usage run to 20 passes: explicitly reported Chat-compatible cache-hit/cache-miss fields are preserved, conflicting breakdowns remain invalid and misses are never treated as cache writes. The runner accumulates these reported components separately. All 17 real local HTTP proxy checks and an isolated JavaScript/TypeScript npm consumer passed after updating the proxy assertion for the new turn metadata. Type declarations and the public consumer fixture cover the new interfaces.

These tests use deterministic responses and local timing. They establish measurement plumbing, not a live-model ranking, token saving, provider bill or completed design. Actual comparisons use the host's explicitly configured providers and matched repeated tasks; fees are not inferred without a documented price basis.
