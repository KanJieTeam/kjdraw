# 本地回归验收：曲线编辑与几何可靠性

日期：2026-09-09。基于 `685c1ad82603aabf99802f23dc0e5ff1c0f6ce19` 的本地修改，版本仍为 `1.0.0-rc.3`。本报告不是上线或 npm 发布证明；用户要求暂停推送，本轮未提交、推送、打标签或发布。

## 产品判断

现在不能宣称已经成为领先的开源 CAD 核心，也不能保证社区传播效果。本轮补齐了一段真实编辑流程并修复数据关联、文件方向和数值精度问题；完整机械制图、建筑平面图和场地图交付仍未全部验收。

发展方向是同一套可直接使用的工作台和可嵌入的开放核心：普通用户不用修改源码即可制图，开发者通过 Vanilla、React、Vue 接入同一产品，勘界的行业能力通过独立扩展使用它。不能维护一套漂亮 Demo、另一套 SDK、再一套勘界内核。

## 本轮实现与修复

| 项目 | 可验证结果 |
| --- | --- |
| 曲线修剪与延伸 | TRIM 支持直线、圆弧、圆；EXTEND 支持直线和圆弧。按实际边界范围计算，修剪中间部分保留两侧，圆修剪后生成原生圆弧。Demo 与嵌入编辑器共用能力和中英文校验。 |
| 组和命名选择集 | 圆变成圆弧、线或弧变成两段时，同一事务同步普通 GROUP 与命名选择集成员；保留顺序、去重，撤销及原生文件重开保持一致。 |
| 顺时针圆弧 DXF | 修复导出成错误互补圆弧的问题；检查端点之外的内部轨迹和实际弧长，而不只检查对象数量。 |
| 大小圆交点精度 | 修复半径差异很大时误判切点和切口偏移；TypeScript 与 Rust 使用一致的稳定计算，没有通过回退 JavaScript 隐藏原生内核错误。 |
| 发布包消费者 | 隔离安装本地打包产物，运行真实曲线编辑、组引用、撤销和 DXF 重开；Vanilla TypeScript、React TSX、Vue 类型示例继续编译。 |

大小圆问题的失败用例为：大圆半径 `10000`、小圆半径 `0.001`，小圆圆心位于大圆圆周。旧计算得到约 `0.001006617584` 的半弦长，而正确值约为 `0.001`；更大的半径比会错误地只返回一个交点。修复后同时检查两端、切口长度、交换圆的顺序、旋转和平移，并通过独立 DXF 读取器复验。

## 未通过或未覆盖的事项

- 本轮没有在 Firefox、Linux、macOS 或新的云端 CI 上验证最终修改；不能把此前云端结果记作本轮通过。
- 曲线编辑限定当前支持的同一正向 XY 平面；连续边界优先操作、复合轮廓、多段线与样条编辑未由本轮补齐。
- BREAK / EXPLODE 的派生成员同步仍需专门完善，不能从 TRIM 的组修复推断所有拓扑操作都已完成。
- 独立 DXF 样例通过不等于任意 DXF 无损，更不代表已支持 DWG。
- 正式出图、完整块与属性编辑、全部图层/文字/标注参数、大图交互性能和第三方独立接入仍是必要工作。
