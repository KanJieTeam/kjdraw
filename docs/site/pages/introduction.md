## Build with KJDraw {#starting-point}

Run the [five-minute guide](https://kanjieteam.github.io/kjdraw/docs/latest/quickstart/), inspect an [editable example](https://kanjieteam.github.io/kjdraw/docs/latest/showcase/), or find the exact method in the [API](https://kanjieteam.github.io/kjdraw/docs/latest/api/). The same KJD document can be edited in the browser, accessed through the SDK, and reviewed in an agent workflow.
