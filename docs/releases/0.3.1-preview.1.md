# KJDraw 0.3.1-preview.1

**Extensible CAD infrastructure for engineering applications and AI agents.**

This release replaces the former single-deployment framing with real, tested deployment-provider contracts while preserving the zero-server browser experience.

## What changed

- Five explicit profiles: browser-local, desktop-local, self-hosted, cloud-assisted and hybrid.
- Three provider families: project storage, compute and streamed scenes.
- A provider registry, profile validation and a runnable integration example.
- Rewritten bilingual positioning, architecture, capability matrix and deployment guide.
- A strict open-source boundary that keeps downstream domain intelligence, customer data, proprietary assets and enterprise services separate.
- Stronger release checks for downstream implementation leakage.

The public GitHub Pages workbench remains browser-local and makes no external requests. A host must explicitly select and invoke a remote provider. Provider wiring is not authentication or authorization; those remain host responsibilities.

This is still a developer preview. DWG, general BRep and certified plotting are not claimed.
