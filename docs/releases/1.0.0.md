# KJDraw 1.0.0

**A stable, programmable CAD foundation for engineering applications and AI agents.**

KJDraw 1.0 is the promotion of the accepted 1.0 release candidate. Stable promotion must use the same verified source contract; it must not add unreviewed features after candidate acceptance.

## Stable contract

KJDraw 1.0 provides:

- a strict TypeScript, ESM-first, zero-runtime-dependency SDK with generated declarations and documented subpath exports;
- transactional KJD documents and deterministic multi-drawing KJP project packages;
- stable IDs/handles, revisions, rollback, undo/redo, selection, snapping and declared 2D CAD operations;
- bounded ASCII DXF interoperability for the published entity/resource/version subset;
- a bilingual browser workbench built on the same public APIs shipped to npm;
- a headless inspect/validate/convert CLI and a versioned plugin compatibility lifecycle;
- review-bound Agent plans with exact-argument and complete-document binding, expiry, one-shot execution, receipts and undo;
- optional Rust/WASM authority and explicit local, desktop, self-hosted, cloud-assisted and hybrid providers;
- reproducible type, package, file, browser, performance, security and release-supply-chain gates.

## Compatibility promise

Patch releases preserve the documented 1.0 public contract and focus on correctness, security and interoperability fixes. Deprecations are documented before removal. New file or geometry claims require public fixtures and executable acceptance evidence.

The exact supported combinations remain in the [capability matrix](../capability-matrix.md). The [machine-readable acceptance matrix](../KJDRAW_1_0_ACCEPTANCE_MATRIX.json) is the release authority, not this announcement.

## Explicit non-goals

KJDraw 1.0 does not claim DWG support, binary DXF, lossless conversion of arbitrary CAD files, general BRep modelling, complete parametric constraints, full font/layout fidelity, real-time collaboration or certified printing. Experimental solid meshes are outside the stable compatibility promise.

The Agent protocol does not replace host authentication, authorization, model isolation or durable audit storage. Plugin permission declarations do not isolate hostile code. Remote processing occurs only through providers explicitly selected and invoked by the host.

## Verify the release

The GitHub release should contain the npm tarball, SPDX SBOM and `SHA256SUMS`, with a GitHub artifact attestation. The npm registry entry should expose provenance for the same tagged commit. Consumers can compare those artifacts before adoption.
