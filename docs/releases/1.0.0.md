# KJDraw 1.0.0

The first stable release of KJDraw's declared 2D CAD SDK, editor and review-bound execution protocol.

## Install

```sh
npm install @kanjieteam/kjdraw
```

For a terminal-enabled AI agent, install the runtime globally and select the CAD Skill:

```sh
npm install -g @kanjieteam/kjdraw
npx skills add KanJieTeam/kjdraw -g
```

## Included

- Transactional editable geometry, revision checks, host-reviewed proposals, undo/redo and supported DXF exchange.
- Bounded missing-read recovery and exact geology description/display-label updates.
- Native DIMASSOC preservation for unrelated edits; complete original reactor-host capture and safe export rejection for changed or unsupported associations.
- One source commit for CI, deployed pages, the attested GitHub package and npm; registry bytes and the `latest` channel are checked after publishing.

## Scope

Publication uses local core regression and exact-commit deployment/package/provenance gates, as explicitly authorized by the maintainer on 2026-10-08. Full industry acceptance, independent users and three-model holdout remain follow-up work, not passed tests. AI/model behavior remains a preview: this release does not claim every instruction succeeds, universal DXF losslessness, DWG support, imported dynamic-block/constraint solving, or 99% token savings.

See [product scope](../1.0-scope.md) and [DXF compatibility](../dxf-compatibility.md). Preserve source drawings and review engineering changes before use.
