# KJDraw 0.3.0-preview.1

**A usable local-first CAD workbench, not only an SDK showcase.**

This preview turns the public playground into a product-shaped reference application. Download the repository and run `node scripts/serve.mjs`, or use the continuously deployed GitHub Pages demo.

## Workbench

- Open or drag-and-drop DXF, KJD and KJP files entirely in the browser.
- Draw lines, polylines, circles, arcs and text.
- Move, copy, rotate, offset and erase selected geometry.
- Measure distance, entity length and area.
- Create and toggle layers, inspect objects and edit common properties.
- Run common operations from the command bar.
- Save lossless KJP projects and export the supported ASCII DXF subset.
- Preview and explicitly confirm an agent-origin command.

## Rendering

The reference canvas now covers common 2D lines, rays, circles, arcs, text, polylines, ellipses, splines, hatches, leaders, dimensions, solid/trace outlines, viewports and tables. Unsupported or lossy cases remain preserved in KJP and are reported instead of silently discarded.

## Developer experience

- TypeScript declarations for the principal SDK, document, project, command and error APIs.
- TypeScript authoring entry and strict incremental migration configuration.
- Existing browser and Node.js ESM imports remain compatible.
- GitHub Pages deploys automatically from verified `main` changes.

## Verification

- 85 SDK, WASM, file, TypeScript contract and sample tests passed locally.
- Browser QA passed real KJP/DXF reopen; line/polyline/circle/arc/text creation; command move; measurement; delete; agent plan/confirm/undo; and 1366/768/390 responsive layouts.
- No external request or page error occurred in the tested browser workflows.

This remains a developer preview. DWG, complete DXF fidelity, certified plotting and general BRep are not claimed.
