# KJDraw 1.0.0-rc.3

This candidate adds geometric construction and parameterized editing to the shared workbench, with selectable layouts for the Demo, Vanilla TypeScript, React and Vue editors.

- Move and copy objects using a base point and destination, with temporary previews and Esc cancellation. Exact command input remains available.
- Drag selected objects; use Undo and Redo to restore geometry.
- Select with left-to-right windows, right-to-left crossing frames and open fences; use Shift to add, Ctrl/Command to remove, and Ctrl/Command+A to select editable objects.
- Drag line endpoints, circle quadrants and polyline vertices using visible grips, with temporary previews, cancellation and a single undo step.
- Protect locked, frozen and hidden layers through the common editing-command path. Both workbenches provide controls to unlock and thaw layers.
- Query model-space selection with `selectEntitiesInBox` / `selectEntitiesByFence`, or use the Canvas renderer's screen-coordinate adapters.
- Select curved hatch boundaries and holes correctly; keep fence tolerance stable across long paths and zoomed-out construction lines.
- Keep long bilingual command prompts inside the host layout; repeated size notifications no longer refit edited geometry underneath the pointer.
- Ignore secondary touch and pen events during active selection and grip gestures.
- Preserve layer, drawing properties and elevation when exploding a polyline into native lines and arcs, including undo and file reopen.
- Preserve per-object colors, linetypes, lineweight and visibility when saving and reopening DXF drawings, including edited imported hatches.
- Trim the picked interval from a line while keeping both remaining sides, their layer/style and elevation. Line extension preserves interpolated height; ray and infinite-line boundaries use their actual geometric domains.
- Navigate with the right-center Select, Pan, Fit, Zoom in and Zoom out toolbar.
- Choose Classic, Compact or Focus without remounting the editor or losing drawing history.
- Update `layout` through React/Vue props or `editor.setLayout()`.
- Share the Precision theme and SVG icons across hosted and embedded workbenches.
- Keep fitted geometry clear of the floating command bar; scale drawing text in model units.
- Correct Demo selection of newly copied and offset objects.
- Add a bilingual workbench guide covering actual drawing operations.
- Draw continuous open/closed polylines, configurable polygons, three-point ellipses, control-point splines, hatches and dimensions.
- Construct circles by center/radius, diameter endpoints or three points; construct arcs by center/start/end or three points.
- Enter absolute, relative and polar coordinates. Finish, close, undo a draft point or cancel without adding unfinished geometry.
- Configure rotation, scale, mirror, rectangular/polar arrays, offset, break/explode, line trim/extend and line-pair fillet/chamfer using shared command definitions.
- Render evaluated splines, native canvas circles/ellipses, and dimension lines with arrows and measured text.
- Export real ANSI31/ANSI37 hatch patterns, preserve interior boundaries, and correct radial/diameter dimension point codes in DXF.
- Keep embedded ribbon buttons in their own hit areas in Safari, including Chinese labels and compact layouts.
- Export edited imported hatches from their current geometry instead of stale source tags.
- Generate real DXF dimension picture blocks and refresh them after an imported dimension is edited. Independent ezdxf checks verify all four supported dimension types and require zero audit errors or fixes.

See the [workbench guide](https://kanjieteam.github.io/kjdraw/docs/latest/workbench/) for the drawing and editing workflows, and the [CAD completeness programme](https://github.com/KanJieTeam/kjdraw/blob/v1.0.0-rc.3/docs/product/cad-completeness.md) for the remaining production work.

## Install

```sh
npm install @kanjieteam/kjdraw@1.0.0-rc.3
```

The candidate uses npm's `next` channel. It does not promote `latest` to stable 1.0. KJP project workflows remain part of the Demo workspace; the embedded editor's file methods support DXF and KJD.

## 验收重点

从空白图纸构造安装板 → 环形阵列螺栓孔 → 添加尺寸 → 撤销/重做 → 保存重开；另外验证多段线、样条、椭圆、填充和精确坐标输入。用方向框选和围栏选中指定对象，再通过夹点调整端点、半径与顶点。锁定图层不可修改，解锁后可继续；拖动途中取消或换图不应留下修改。切换三种布局后，编辑器实例、图纸与历史应保持不变。右侧导航只改变视图，不修改图元。

这仍是候选版：本次修复不代表已补齐全部桌面 CAD 工作流或完成最终 1.0 验收。
