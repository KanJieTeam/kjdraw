# KJDraw 0.5.0-preview.1

**DXF compatibility claims now have a reproducible public evidence trail.**

## Added

- Seven original ASCII DXF fixtures spanning every declared R14, 2000, 2004, 2010, 2013, 2018 and 2024 target label.
- A dependency-free audit command that records fixture hashes, detected source family, written header code, entity/resource counts and semantic round-trip findings.
- Stable-handle and geometry/text/resource-reference comparison while allowing importer-generated internal object IDs to change.
- A dedicated CI gate, test and public compatibility page.
- Aligned repository, SDK package and runtime-reported version metadata.

## Verification

- 7/7 declared-version synthetic fixtures pass read, validation, target write, reopen and semantic preservation checks.
- 88 public automated tests pass across SDK, files, projects, deployment, WASM and samples.
- Repository release checks and the standalone static build pass.

This corpus proves the exact public ASCII DXF core subset. It does not certify arbitrary CAD files, other CAD applications, binary DXF, DWG, complete plotting resources or font fidelity.
