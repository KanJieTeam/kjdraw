# KJDraw 0.2.0-preview.1

**Local-first CAD infrastructure for engineering applications and AI agents.**

This first standalone developer preview opens the shared KJDraw SDK and Rust/WASM kernel, with a browser playground built on public interfaces.

## Try it

Download the source ZIP, extract it, install Node.js 22+, and run `node scripts/serve.mjs` from the extracted directory. Open http://localhost:4173.

The synthetic sample supports selection, basic drawing, layers, undo, KJP downloads and ASCII DXF export. Preview a survey-point move in the Agent Command Lab and confirm it to produce an undoable revision. The demo is deterministic; no model API is connected.

## Included

- Framework-independent JavaScript SDK with no runtime npm dependencies.
- Rust kernel source and a rebuildable WASM artifact.
- Original synthetic sample, English/Chinese README, architecture and capability limits.
- CI definitions for Node.js on Windows/macOS/Linux and Rust/WASM on Linux.
- Downstream policy for Kanjie to adopt the same public core.

## Limitations

Developer preview, not a certified production CAD. No supported DWG, complete DXF fidelity, complete plotting pipeline or general BRep. Some stored entity types are not rendered in the minimal playground. Host applications own identity, approval binding and isolation. See [status](../status.md).
