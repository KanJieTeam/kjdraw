# KJDraw 0.4.0-preview.1

**A generic CAD workbench that behaves like a project, not a single demo canvas.**

## Workbench additions

- Create and switch between multiple drawings in one KJP project.
- Capture named project snapshots across all drawings.
- Shift-click to build a multi-object selection; move, copy, rotate and delete the selection as one command.
- Toggle drawing grid and orthographic point constraints.
- Render supported geometry nested inside block inserts.
- Preserve the existing open/edit/export/reopen and Agent plan/confirm/undo workflows.

## Verification

- 86 public SDK, deployment, WASM, file and sample tests pass.
- Browser QA covers multiple drawings, project snapshots, Grid/Ortho, Shift multi-selection, grouped transforms/deletion, drawing tools, file round trips, transactional Agent commands and responsive layouts.
- The tested public workbench makes no external requests and reports no page errors.

This remains a developer preview. Complete block attributes, certified plotting, DWG and general BRep are not claimed.
