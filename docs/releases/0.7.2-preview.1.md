# KJDraw 0.7.2-preview.1

This release makes the public experience feel like an embeddable CAD product rather than a project landing page.

## Highlights

- A full-height, familiar CAD workbench is now the default live demo.
- The UI selects Chinese or English from the browser and offers a persistent language switch.
- React and Vue developers get complete state/lifecycle integration examples.
- Tagged GitHub releases receive the exact npm package artifact.

## Verification

- 93 automated repository tests pass.
- Real-browser QA covers both languages, desktop/mobile layouts, drawing, selection, editing, Agent review, DXF and KJP workflows.
- The package remains dependency-free at runtime and passes a clean npm consumer install.
