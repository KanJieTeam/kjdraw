# KJDraw 0.6.0-preview.1

**The TypeScript migration now changes source authority, not just file extensions.**

## Added

- TypeScript-owned deployment Provider source with concrete project-store, compute and scene interfaces.
- A dependency-free build that generates the committed browser/Node ESM artifact from that TypeScript source.
- CI and automated tests that fail whenever generated JavaScript is stale.
- Stronger declaration types and a version-alignment gate across the repository, package and runtime SDK.
- A published migration policy for incrementally moving the remaining JavaScript-owned modules.

## Verification

- 89 public automated tests pass.
- TypeScript source reproduces the committed ESM artifact exactly.
- 7/7 declared-version DXF fixtures, release checks, static build and real browser workbench QA pass.

This is the first source-owned vertical slice. The repository does not yet claim that every SDK module is TypeScript-owned or compiler-typechecked; that boundary is explicit in the migration guide.
