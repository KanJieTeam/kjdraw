# KJDraw 0.7.0-preview.1

**AI agents now receive a review boundary enforced by the SDK, plus a package path designed for one-command adoption.**

## Agent protocol

- Register AI proposals against exact command arguments, document identity, revision and fingerprint.
- Require reviewer identity and reject argument substitution or stale document state.
- Enforce host-controlled expiry, rejection and one-shot consumption; replay fails closed.
- Return the immutable binding record in the plan receipt and expose a short digest in the workbench.
- Keep transactional execution receipts and undo after confirmation.

## Developer onboarding

- Added a publishable `@kanjieteam/kjdraw` layout with no runtime dependencies.
- Added a packaged self-import quickstart that creates, edits and reopens real geometry.
- Added a manual npm workflow that verifies tests, generated ESM, exact release tag, package contents and provenance before publishing previews under `next`.
- Documented that the first npm registry publication still requires `@kanjie` scope permission and an npm Actions token.

## Verification

- 93 public automated tests pass, including plan tampering, drift, expiry, replay and packaged quickstart workflows.
- 2 TypeScript-owned modules reproduce committed ESM exactly.
- 7/7 DXF fixtures, release checks, static build and real Chrome workbench QA pass.

The binding protects a single SDK host process. It does not replace host authentication, permissions, distributed authorization, model isolation or cryptographic signing across trust boundaries.
