# KJDraw 1.0.0-rc.4

This is a public **test candidate**, not the stable 1.0 release. It brings the source changes since rc.3 into an installable candidate, subject to the exact-tag release checks and npm publication.

- Add a separate browser AI chat. A visitor selects a common model preset and supplies their own key in memory; drawing changes remain reviewable. No hosted model key or autonomous approval is supplied.
- Expand the local Skill/CLI CAD workflow and make proposal replies smaller. The model proposes changes; the host reviews and commits them.
- Add published-package first-use checks covering proposal, review, KJD/DXF save and reopen. A scripted approval in this check is a fixture, not independent human acceptance.
- Disable remote geology knowledge updates by default unless the host supplies an explicit signature verifier. Bundled knowledge remains available offline. A content hash alone is not a publisher signature.
- Publish reproducible token-efficiency pilots, including failures. They do **not** prove that 99% of tasks save tokens.
- Add a preregistered three-arm, ten-round correctness protocol and an independent ezdxf check for unintended DXF record changes. A frozen task corpus, target-geometry scorer, real model runs and independent holdout are still pending.
- Keep the source-based AI installer pinned to a separately verified source commit. It is not the npm package and does not update running installations automatically.

## Install after publication

```sh
npm view @kanjieteam/kjdraw@1.0.0-rc.4 version
npm install @kanjieteam/kjdraw@1.0.0-rc.4
```

If the version query fails because rc.4 is absent, this source candidate has **not** yet reached npm. Check the [release status](https://github.com/KanJieTeam/kjdraw/blob/main/docs/status.md) and do not substitute `latest` silently.

Stable 1.0 still requires clean-system independent first use, real-drawing corpus comparisons and a frozen multi-model correctness study. See the [roadmap](https://github.com/KanJieTeam/kjdraw/blob/main/docs/roadmap.md).
