# KJDraw 1.0.0-rc.1 — Release Candidate

**The first candidate for KJDraw's stable, embeddable CAD contract.**

KJDraw 1.0 brings a strict TypeScript SDK, a product-shaped browser workbench, portable KJD/KJP projects, bounded ASCII DXF interoperability, optional Rust/WASM authority, plugins and a reviewable command protocol for AI agents into one public foundation.

> This document is prepared before tagging. The release workflow must refuse the candidate unless every repository-owned gate passes on the exact commit; the three explicitly marked candidate-verification gates are then closed by hosted browser, live deployment and provenance evidence from that immutable run.

```ts
import { createKJDrawSDK } from '@kanjieteam/kjdraw'

const cad = createKJDrawSDK()
const drawing = cad.createDocument({ documentId: 'candidate-review' })
await cad.executeCommand('CREATE', {

  payload: { center: [0, 0, 0], radius: 25 },

```

## What is in 1.0

- Strict TypeScript authority for the complete public SDK runtime, with reproducible browser/Node ESM and generated declarations.
- Atomic CAD documents with stable object identity, revisions, rollback, undo/redo, selection, snapping and declared 2D editing operations.
- KJD documents and deterministic ZIP64 KJP projects with multiple drawings, hashes, snapshots, journals and resource budgets.
- ASCII DXF support for the published subset, backed by the seven-version synthetic corpus and pinned ezdxf 1.4.4 bidirectional audits.
- A bilingual CAD workbench whose launch journey covers inspect, edit, natural-language proposal, visual diff, approval, receipt, save, fingerprint reopen and undo.
- A dependency-free npm runtime, isolated Vanilla/React/Vue compilation, a local CLI and a complete TypeScript plugin starter.
- Agent plans bound to exact arguments and complete document content with Web Crypto SHA-256, expiry, reviewer identity and one-shot consumption.
- Rebuildable Rust/WASM document authority, geometry predicates and explicitly bounded solid-mesh operations.
- Explicit browser, desktop, self-hosted, cloud-assisted and hybrid provider contracts.
- Generated API docs, search/deep links, large-document performance budgets, input limits and a provenance-ready release pipeline.

## Candidate evidence

Before the tag is promoted, the same commit must retain:

- the complete automated repository suite passing;
- strict typecheck, generated ESM/declaration parity and packed-package consumer verification;
- Rust tests and rebuildable WASM artifact checks;
- zero-error/zero-fix ezdxf audits for the declared cross-implementation subset;
- the synthetic 10,000-entity core budget;
- Chromium, Firefox and WebKit hosted launch journeys;
- live Demo/Docs verification, npm provenance, GitHub artifact attestation, SBOM and SHA-256 checksums.

Local pre-tag evidence recorded for this candidate work included 112/112 repository tests, 15/15 Rust tests, the packed consumer audit, the 10,000-entity budget and the Chromium launch journey. Hosted and release-service evidence must still come from the immutable candidate run.

## Migration from the 0.x previews

- Use Node.js 22 or newer and ESM imports.
- Treat `activeDocument` and `activeSelection` as nullable until a document is attached.
- Await Agent plan registration/consumption and command-envelope execution; content binding now uses async Web Crypto.
- Import supported subpaths from package exports rather than reaching into undocumented files.
- Rebuild generated ESM and declarations after changing TypeScript source; CI rejects drift.
- Re-test custom plugins against the versioned manifest, declared contributions and explicit permission grants.

## Deliberate limits

This candidate does not include DWG, binary DXF, arbitrary-DXF losslessness, general BRep modelling, full parametric constraints, complete font/layout fidelity, real-time collaboration or device-certified plotting. Solid meshes remain experimental. Plugin permissions are cooperative; hostile-code isolation belongs to the host.

Please report regressions with a minimal synthetic file, exact candidate version and environment. Do not upload confidential engineering drawings.
