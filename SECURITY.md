# Security

KJDraw is currently a developer preview. No supported long-term release or response-time SLA is offered yet.

Report vulnerabilities privately to **hanwei5512@126.com** with reproduction steps and the affected version. Do not attach confidential engineering drawings; provide a synthetic reproduction where possible. Avoid publicly disclosing exploit details before maintainers have had an opportunity to assess them.

Treat imported CAD files, project packages and third-party plugins as untrusted. Plugin permission declarations are host cooperation mechanisms, not process isolation. AI confirmation metadata does not authenticate users. Applications must implement appropriate approval binding, identity, resource limits and isolation for their deployment.
